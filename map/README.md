# Atlas map style

`atlas-style.json` is a pinned, locally hosted derivative of OpenFreeMap's
Liberty style, retrieved on 2026-10-05 and recolored for the journal. It keeps
OpenFreeMap's remote vector tiles, raster overview, glyphs, and sprites.

When updating it, preserve source attribution and verify the Atlas at world,
country, and city zoom levels before replacing the file.

- OpenFreeMap: <https://openfreemap.org/>
- OpenMapTiles schema: <https://openmaptiles.org/schema/>
- OpenStreetMap copyright: <https://www.openstreetmap.org/copyright>
